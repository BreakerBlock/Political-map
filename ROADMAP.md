# BharatYatra roadmap

## Priority backlog (from Utkarsh, 2026-10-18)
- [x] **Zoomed-in map asked for an API key** — replaced CARTO tiles with key-free Esri tiles (World_Terrain_Base for the overview, World_Imagery satellite from zoom 11, plus a Map/Satellite toggle). Neither draws borders or labels, so `india-boundary.geojson` is the only boundary shown. *(2026-10-18)*
- [x] **Road distances between trip stops** — each leg now shows road km and estimated drive time from the public OSRM server (no key), with the road route drawn on the map. Legs to/from Andaman & Lakshadweep, or with no road, fall back to clearly labelled straight-line distance. Results are cached per leg; requests are debounced. *(2026-10-18)*
- [x] **Visual refresh, pass 5 — trip pins & roomier itinerary** — trip stops are now **numbered pins** in their category colour (number in a white disc) that leave the cluster group, so a stop's number never hides under a cluster bubble; earlier stops sit on top when two stops overlap, and a stop removed from the trip drops back into its cluster with its popup still open. Hovering a stop in the timeline lifts and pulses its pin and brings it to the front. On desktop, opening **My trip** folds the category grid, state picker and search into one line (Categories + coloured dots for the active categories + a **Filters ▾** button to peek), so a 5-stop trip and its actions fit without scrolling at 1366×800. *(2026-10-21)*
- [x] **Visual refresh, pass 4 — phone header & trip reordering** — on phones the header is now one row: flag + wordmark, the search box (moved up from its own row) and a round ✉ Suggest button, so the map is ~54px taller on a 390px screen (637 → 691px). Trip stops can be **dragged to reorder** by their number or grip (mouse and touch; the list auto-scrolls, the other stops slide to make room, legs fade while dragging, and the dropped stop flashes). The grip also works from the keyboard with ↑/↓. Phones show grip + ✕ only; desktop keeps the ↑/↓ buttons. *(2026-10-20)*
- [x] **Visual refresh, pass 3 — trip planner & sidebar** — the trip panel is now a timeline: a summary card (stops, road km, drive time, straight-line km for sea legs) over a vertical line joining numbered stops in category colours, with each leg as a chip (car icon for road legs on a solid line; dashed line and plane icon for sea/air legs; spinner while routing). Clear actions (Share trip link, Shortest order, Show on map, Email, Clear) and an illustrated empty state. "Showing N places · Trip · total in repo" became **Places / My trip** tabs (which also open and close the drawer on phones), and the trip counter bumps when a stop is added. Desktop categories are a tidy two-column grid. The boundary disclaimer moved bottom-left so it no longer collides with the attribution, and the attribution fits on one line on phones. Trip stop names are now HTML-escaped. *(2026-10-19)*
- [x] **Visual refresh, pass 2 — popups & sidebar** — popups are now photo-led cards: 168px Wikipedia photo with a shimmer while it loads and a fade-in, place name and state set over the photo, category chip, a coloured header when there's no photo, and a soft pop-in animation. Each popup has Directions (Google Maps), Wikipedia and **Suggest edit** (email to utkarsh.khurana@outlook.com) links. Popups size to the screen and no longer slide under the map controls on phones. Sidebar cards got larger category tiles, a category + state line, 2-line descriptions, hover lift, a highlight for the place whose popup is open, and a one-tap **+ / ✓ Add to trip** button. Fixed Neer Mahal's coordinates (23.50, 91.32). *(2026-10-18, run 2)*
- [x] **Visual refresh, first pass** — terrain basemap, misted neighbours with a warm wash inside India, saffron-halo boundary, teardrop category pins, cream clusters with coloured rings, tricolour header rule, serif state labels, less clutter on phones. *(2026-10-18)*

## Done after the backlog
- [x] **Day-by-day trip plan** — the My trip timeline now splits the route into driving days (Day 1, Day 2 … headers with each day's drive time and km), marks overnight stops with a 🌙 Night N tag, alternates the route colour per day on the map, and adds a "days" count to the trip summary. A **Max drive / day** switch (4 h / 6 h / 8 h, remembered on the device) re-plans instantly. Sea/air legs to the islands become their own travel day; a single leg longer than the limit is flagged as a long day; days that still use straight-line estimates are marked ≈. Email itineraries include the day headings. Fix: trips restored from a shared link or the browser now show their numbered stop pins immediately (they used to appear only after the map re-rendered). *(2026-10-22)*
